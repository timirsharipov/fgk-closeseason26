# Сервер аллейката - Google Таблица + Apps Script

Бесплатно, без хостинга. Все данные лежат в одной Google Таблице:

| Лист | Что там |
|---|---|
| **Настройки** | время старта, радиус засчёта скана, адрес сайта, цены, дата повышения цены, «Гонка только после оплаты» |
| **Регистрации** | кто зарегистрировался с сайта, сколько должен и галочка **«Оплачено»**. В колонке «Допуск» напишите `нет`, чтобы не пускать человека в гонку |
| **Точки** | точки маршрута: название, координаты, ценность, финиш, описание, фото |
| **Сканы** | журнал всех отметок: кто, какая точка, расстояние, статус (`ok`, `далеко`, `проверить фото`, …), ссылка на фото. В топ идут только `ok` |

## Установка (≈10 минут)

Сервер ставится в **таблицу ответов Google Формы** («FGK CloseSeason 26 (Ответы)»).
Лист с ответами формы остаётся как есть; все ответы - и старые, и новые -
автоматически переносятся в «Регистрации». Так работают и форма, и сайт.

1. **Откройте таблицу ответов** и в ней «Расширения → Apps Script».
2. **Вставьте загрузчик**: удалите всё в редакторе, вставьте содержимое [`Loader.gs`](Loader.gs), нажмите 💾.
   Сам сервер (`Code.gs`) загрузчик берёт из GitHub (`fgk-closeseason26/main`), поэтому
   вставлять код и заново разворачивать после обновлений не нужно.
3. **Запустите настройку**: сверху выберите функцию `setup` → «Выполнить».
   Google попросит доступ: «Проверить разрешения» → ваш аккаунт →
   «Приложение не проверено» → «Дополнительные настройки» → «Перейти в проект» → «Разрешить».
   Появятся листы «Настройки», «Регистрации», «Точки», «Сканы» и меню «Аллейкат»,
   а уже записавшиеся через форму окажутся в «Регистрациях».
4. **Опубликуйте сервер**: «Начать развёртывание → Новое развёртывание» →
   ⚙ «Веб-приложение»; «Запуск от имени» - **Я**; «У кого есть доступ» - **Все**.
   Скопируйте URL, который заканчивается на `/exec`.
5. **Подключите сайт**: этот URL - в `config.js` → `apiUrl`.
6. **Опубликуйте сайт** (например, GitHub Pages).

Если в форме ник написан не как ник Telegram (например, имя по-русски), он перенесётся
как есть - поправьте его в «Регистрациях», иначе человек не сможет войти в гонку.

## Точки

1. Заполните лист «Точки» (пример-строки замените):
   - **ID** - можно не заполнять: проставится сам (`p1`, `p2`…, у финиша - `fin`)
   - **Координаты** - одной строкой, как копируют из карт: `55.752000, 37.617500`
     (Яндекс Карты: правый клик по месту → «Что здесь?» → нажать на координаты, они скопируются)
   - **Ценность** - сколько очков даёт точка
   - **Финиш** - `да` у клуба
   - **Описание** - по желанию, показывается на странице точки
   - **Фото** - по желанию. Вставьте картинку **в ячейку**: «Вставка → Изображение →
     Изображение в ячейке». Если фото уже висит поверх таблицы - нажмите на него →
     ⋮ → «Поместить изображение в выбранную ячейку». Можно и ссылку на картинку.

   Колонки ищутся по названию, порядок можно менять; лишние колонки сервер не читает.
2. Меню «Аллейкат → Обновить ID и фото точек» - пустые ID проставятся сами, а фото из ячеек сохранятся в папку «FGK CloseSeason 26 - фото точек»
   на вашем Диске (доступ по ссылке) - ссылка в колонке «Фото для сайта». Поменяли фото -
   нажмите пункт меню ещё раз. Картинку можно скопировать/распечатать прямо из таблицы.

## Отметка по фото

Если у гонщика не работает геолокация (глушат, уводит за город), он отправляет с сайта фото с точки.
Фото ложится на ваш Диск в папку «FGK CloseSeason 26, фото с отметок», а в «Сканы» - строка
со статусом **«проверить фото»** и ссылкой в колонке «Фото». Посмотрели фото:

- точка верная - поменяйте статус на `ok`, она засчитается временем отправки фото;
- не верная - напишите `отклонено`, гонщик сможет отметиться ещё раз.

Пока фото не проверено, гонщик видит у точки «фото на проверке».

## Оплата

Участник платит сам переводом по СБП по номеру телефона - без комиссии.
Сумму считает сервер при регистрации: «Цена, ₽», а с даты «Повышение цены» -
«Цена после повышения, ₽»; девушкам - 0 (сразу отмечено «Оплачено»).

1. Сайт показывает участнику сумму, номер и просит указать ник в сообщении к переводу.
2. Видите перевод в приложении банка → ставите галочку «Оплачено» у этого ника.
3. У участника на сайте статус сменится на «оплачено ✓» (кнопка «Обновить статус»
   или при следующем заходе). Во время гонки неоплатившим показывается напоминание.

«Гонка только после оплаты» = `да` - сканы без галочки «Оплачено» не засчитываются.
По умолчанию `нет`, чтобы задержка с отметкой не остановила гонщика на трассе.

## Тестовый режим - разработка и проверка точек

Откройте на своём телефоне `https://<сайт>/?test=<Ключ администратора>` - телефон запомнит
режим, вверху появится полоса «Тестовый режим». Выйти - кнопкой «выйти» или ссылкой `?test=off`.

- точки и топ видны в любое время, не дожидаясь старта;
- кнопка «Проверить гео (тест)» на странице точки показывает, сколько метров до её координат
  в таблице (засчитается ли гонщику). Кнопка «Записать сюда координаты точки» ставит
  в таблицу координаты места, где вы стоите;
- тестовые отметки пишутся в «Сканы» как «(тест)» со статусом «тест: …» и в очки не идут.

Без ключа тестовый режим не включается - раньше старта точки никто не увидит.

## Обновления сервера

Код сервера - `server/Code.gs` в ветке `main` репозитория `fgk-closeseason26`. Загрузчик берёт его
оттуда сам (кеш - 2 минуты, копия на случай недоступности GitHub хранится в свойствах скрипта).
Сразу подхватить новую версию - служебная команда `reload` с ключом администратора.
Перед каждым пушем - `node server/test/server.test.js && node server/test/loader.test.js`.

## Как это работает

- До старта сервер принимает регистрации и не отдаёт точки.
- С момента старта регистрация закрыта; точки и топ видны всем.
- Вход - по нику из регистрации. Отметка засчитывается, если телефон не дальше
  радиуса (+ до 50 м на погрешность GPS) от точки, или по фото после проверки.
- На каждой точке первый получает «Очки за первое место», каждый следующий на 1 меньше
  (не меньше минимума), ценность точки - множитель. При равенстве выше тот, кто набрал очки раньше.
