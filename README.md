# FGK CloseSeason 26

Сайт закрытия сезона: регистрация до старта и аллейкат по QR-точкам после.

- **До 30.10, 20:00 (МСК)** - описание, цены, регистрация, обратный отсчёт.
  После регистрации - сумма и реквизиты для перевода и статус оплаты,
  который организатор отмечает галочкой в таблице.
- **С 20:00 до 23:00** - регистрация закрыта; список точек виден всем.
  Вход по нику из Telegram нужен, чтобы отметки засчитывались.
- **QR на точке** - камера открывает персональную ссылку точки, сайт берёт
  геолокацию, сервер проверяет секрет QR и расстояние. Если гео глушат или уводит за город,
  гонщик отправляет фото с точки, организатор проверяет его в листе «Сканы».
- **Очки** - на каждой точке первый получает больше всего, каждый следующий меньше,
  ценность точки умножает очки. Финиш в верке отмечается последним.
  Топ скрыт до конца аллейката.

## Файлы

- `index.html`, `style.css`, `app.js` - сайт
- `config.js` - адрес сервера (`apiUrl`); пустой - демо-режим
- `data.js` - демо-данные
- `server/` - сервер на Google Таблице + Apps Script, [инструкция по установке](server/README.md)
- `mockups/` - скриншоты состояний

## Демо

Пока `apiUrl` пустой (или в адресе есть `?demo=…`), сайт работает на демо-данных,
а внизу есть переключатель состояний: `?demo=reg | pay | guest | racer | scan-ok | scan-far | scan-guest`.
